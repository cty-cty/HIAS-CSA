# HIAS-CSA (Course Selection Assistant)

国科大杭州高等研究院 2026 秋季预选课辅助工具。

## 功能

- 按课程名称、编码、教师、教室、院系、学科/专业、课程类别和星期筛选课程
- 汇总已选课程数量与学分
- 自动识别上课时间与教学周冲突，并显示冲突课程和时段
- 为存在平行班的课程提供无冲突替代班次
- 按周生成模拟课表
- 查看培养方案课程覆盖情况
- 按闭卷、开卷、报告、实践等类型查看考试压力
- 查看课程学分、教师、教室、考试方式、授课方式等详细信息
- 导出已选课程 CSV
- 支持单文件离线使用，选课结果保存在当前浏览器中

## 本地运行

```bash
npm install
npm run dev
```

## 生成离线版

```bash
npm run build:offline
```

生成后的单文件网页位于项目上一级目录，可直接用现代浏览器打开。

## 数据说明

- 课程数据依据 2026 年秋季学期课表整理。
- 培养方案依据已提供的培养方案文件整理。
- 课程余量和选课人数不是实时数据。
- 本项目仅用于选课规划，最终安排以学校通知和正式选课系统为准。
