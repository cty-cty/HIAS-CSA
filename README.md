# HIAS-CSA (Course Selection Assistant)

国科大杭州高等研究院 2026 秋季课程预选模拟工具。

## 项目介绍

HIAS-CSA 是面向国科大杭州高等研究院 2026 级研一新生的课程查询与预选课模拟工具，整合了已整理的 2026 年秋季学期 158 门课程信息，并提供依据培养方案整理的 2027 春季计划课程，帮助同学查询课程、检查时间冲突、统计学分并生成个人模拟课表。

项目中的课程和培养方案数据来自已有课表及相关材料的整理，仅供课程查询、选课规划和模拟使用，不代表学校最新或最终安排。正式选课前请务必自行核对，并以学校教务系统、培养方案原文件和正式通知为准。

网页默认通过 GitHub Pages 在线使用，也可以按需下载为单文件离线网页。无需登录或安装软件，已选课程保存在当前浏览器中。

## 主要功能

- **多条件课程查询**：支持按课程名称、课程编码、教师、教室等关键词搜索，并可按开课院系、所属学科/专业、课程类别和上课星期筛选。
- **完整课程信息**：集中展示课程学分、学时、任课教师、开课院系、所属学科、上课时间、周次、教室、考试方式、授课方式及选课人数等信息。
- **选课工作区**：首页直接进入课程列表，搜索和筛选仅在选课页显示；筛选条件可逐项取消，“已选”入口会清除其他筛选，完整展示当前学期的选课。
- **已选课程与学分统计**：点击课程卡片上的“加入课表”按钮即可预选，电脑端右侧方案栏、手机端底部快捷栏实时展示门数和学分。加入、移除、换班和清空后支持撤销上一步操作。
- **自动检查课程冲突**：发现上课时间和教学周次重叠时，会明确提示哪两门课程发生冲突，并显示具体冲突时段。
- **一键寻找替代班次**：若同一门课程存在其他无冲突班次，可直接查看并选择替代班次，快速调整选课方案。
- **选课方案体检**：结合当前培养方向检查学期有效学分、课程冲突、核心课与专业课、公选课、创新创业模块、体育课限制及课程属性设置情况。
- **学位课属性**：可将每门已选课程标记为学位课、非学位课或未确定；研讨课、实验课、实践课和科学前沿讲座会按规则限制为非学位课，并按学期保存在浏览器中。
- **课程归属口径**：HIAS 讲堂计入公共选修，不计入专业非学位；科学前沿讲座计入专业非学位，不计入公共选修。两者都不计入秋季/春季有效学分最低 10 学分。
- **模拟周课表**：可按照第 1—20 周分别查看个人课表，课程按星期和节次排列，发生冲突的课程会用红色标出。
- **培养要求参考**：结合培养方案、历史已修和各学期已选/计划课程，累计展示分类学分及核心/专业门数；下方课程库和具体排课仍按当前学期展示。预选与计划课程不代表已经修完。
- **考试压力分析**：按照闭卷、开卷、报告/论文、实践/技能及其他考核方式对已选课程分类，辅助平衡不同类型的学习和考核压力。
- **选课须知**：集中展示 2026-2027 学年选课开始与截止时间、学期选课学分门槛、核心课/专业课认定、公选课限制、增退选与学位属性变更时限、课程评估和咨询渠道。
- **导出选课结果**：按文件夹中的 `课表模板.xlsx` 导出 CSV，列顺序为“课程名称、星期、开始节数、结束节数、老师、地点、周数”，每个上课安排单独占一行。
- **WakeUp 课程表导入**：导出的 CSV 与 WakeUp 课程表模板字段和行结构一致；确认课程、时间和周数符合实际后，可直接导入 WakeUp 使用。
- **本地保存**：选择结果会自动保存在当前电脑的浏览器中，不会上传到项目服务器。
- **清空当前学期选课**：可在方案栏或“已选”列表中清空课程，操作前会提示学期和课程门数并要求确认；其他学期和历史已修记录保留。
- **培养设置与补充建议**：首次打开自动弹出“培养设置”，确认培养方向及英语免修免考资格；点击“完成设置，开始选课”后，同一浏览器不再自动弹出，仍可从顶部手动修改。未完成就关闭窗口时，下次打开仍会提醒。补充建议通过方案栏或“已选”列表按需打开，连续选课时不会自动弹窗。
- **英语免修免考学分**：选择“已获得”后，方案学分合计自动计入 3 学分，顶部、侧栏、手机底栏和培养要求页同步更新。已选或历史已修英语课程不会重复计分；取消资格后重新按实际课程计算。免修学分不会增加课程门数或生成课表条目。
- **一键更新课程数据**：在“当前课程数据学期”区域选择新的课程数据 JSON，即可在浏览器本地加载新学期或修订后的课程表；更新同一学期时会按课程编码尝试保留已选课程，并提示未匹配项目。
- **按学期隔离选课记录**：不同学期拥有独立的已选课程、学分统计、冲突检查和模拟课表，切换学期不会串课。
- **可扩展培养方案**：在“培养方案参考”页导入其他学科或专业的培养方案 JSON。导入内容只保存在当前浏览器，不会覆盖内置方案。
- **学院分组筛选**：培养方向和课程学科/专业筛选根据培养方案中的可选 `college` 字段自动生成学院一级菜单。新增学院时只需补充方案数据，不需要修改页面分组代码。
- **培养方案体检与推荐**：规则层统一区分本学期必须处理、培养方案进度和待确认事项；“优化当前方案”以现有已选课程为锁定条件，先排除硬冲突和重复课程，再生成最多三类可预览方案。推荐分数只是网站策略，不代表学校评价。

### 2026-09-09 规则与规划修正及验收

- 培养进度与推荐共享“历史已修 + 各学期已选/计划”的去重统计；课表、冲突、学期有效学分和 WakeUp 导出仍按当前学期隔离。预选不等于已修完成。
- 跨专业核心/专业课设置为学位课后，纳入专业学位的规划合计，同时单列“方案认可范围内 + 非本专业专业类课程”。本专业核心与专业门数独立检查，不以先满足2+2作为计分前提。学位属性须核对学校官网、学院培养方案与教务系统；所有课程安排均建议与导师确认合理性。
- 普通公共选修2学分 + 创新创业1学分 = 公选体系3学分，只累计一次。HIAS归公共选修，科学前沿归专业非学位；两者不计学期最低10学分。
- 春季《硕士学位英语》与秋季英语A使用同一课程family。免修计入培养学分但不生成课程、不删除已选英语、不重复累计。学期实际修读学分与免修3学分分别展示；若是否达到最低10学分仅取决于免修口径，显示黄色待确认，不直接判定选课错误。正式材料未明确此边界，需教务确认。
- 推荐按需生成、保留锁定课程。使用最多3组、每组最多10次迭代的动态贪心搜索，每次重新计算边际贡献；满足当前学期硬要求即停止，余下培养目标留待后续学期。剔除同历史/其他学期重复课程，保留合法非学位用途；跨专业扩展需主动开启。相同结果去重，不承诺最优或一定能补齐。
- 正式数据导入保留不同教学班，升级匹配计划记录并迁移选课属性。更新是增量合并，未匹配旧数据/选课保留；匹配多个班次时导入前列出拟选班次并要求确认，导入后可换班。
- 普博按学院已明确口径检查：总学分不少于38、公共必修不少于11、专业学位课不少于16、公共选修不少于2；具体博士核心课/专业课门数和不同培养类型的课程结构仍标为 verification，不套用硕士2+2。直博、硕博连读专业学位至少16学分，独立培养类型入口沿用原培养设置。

轻量验证：`npm run test:rules`（基础规则与回归）；类型检查、线上构建与离线构建仍使用原工具链。文件修改清单、正式材料核对、测试结果及未确认事项见 [修复与验收报告](FIXES-2026-09-09.md)。本地验收不代表已经发布到线上。

### 更新课程数据文件格式

课程数据文件可以直接使用项目中的 `app/courses.json` 数组，也可以使用带学期信息的 JSON：

```json
{
  "termId": "2027-spring",
  "label": "2027 春季",
  "audience": "适用对象以对应培养方案和学校通知为准",
  "courses": []
}
```

其中 `courses` 内的课程字段需与 `app/courses.json` 保持一致；`audience` 可选，用于更新页面顶部的适用对象提示。如果没有提供 `termId` 或 `label`，网页会根据文件名建立学期名称。

### 春季计划课程与正式课表

`app/courses-spring.json` 是依据物理与光电工程学院 2026—2027 课程设置和学校选课须知整理的“培养方案明确的春季计划课程”，不是 2027 春季正式课表。计划课程使用 `scheduleStatus: "planned"` 与 `dataStatus: "planned_course"`，没有正式课程编码、时间、班次、教室、容量、已选人数或考核方式时保持未知，页面会显示“待春季正式课表公布”。`SP2027-*` 仅作为内部兼容标识，不代表学校正式课程编码。

计划课程可以用于跨学期培养方案规划、判断培养缺口是否可以留到春季，以及计算课程机会成本；不能用于精确时间冲突、教室、班次、名额或已选人数判断。光电信息工程的春季计划专业课程包括 FPGA 电路软硬件设计、专业英语、超快现象与超快光谱、量子光学、数字图像处理、非线性光学导论，其中 FPGA 电路软硬件设计在培养方案中标注为秋、春均开设。春季公共选修课程在正式名单未知时只说明“春季仍可修读公共选修课程，实际课程以届时教务系统为准”，不会预先生成具体公共选修课程。

未来导入 2027 春季正式课程数据时，系统按 `officialCode`、`canonicalCourseId`、标准化课程名称加所属专业依次匹配计划课程；匹配成功后以正式课表记录替换计划记录，避免同一课程重复显示。正式课程应使用 `scheduleStatus: "confirmed"` 与 `dataStatus: "official_schedule"`。

### 导入其他培养方案

在“培养方案参考”页点击“导入培养方案 JSON”，可上传一个方案数组，或上传包含 `plans` 字段的 JSON。每个方案至少需要以下字段：

```json
{
  "plans": [
    {
      "id": "example-master",
      "label": "示例方向 · 专硕",
      "degree": "专业型硕士",
      "program": "示例专业",
      "college": "示例学院",
      "code": "0854 示例代码",
      "totalCredits": 25,
      "publicRequiredCredits": 8,
      "degreeCourseCredits": 12,
      "professionalNonDegreeCredits": 2,
      "publicElectiveCredits": 2,
      "innovationCredits": 1,
      "coreMinimum": 2,
      "professionalMinimum": 2,
      "coreCourses": ["核心课程名称"],
      "professionalCourses": ["专业课程名称"],
      "source": "培养方案文件名称或来源说明"
    }
  ]
}
```

`college` 是可选字段，用于培养方向菜单和课程学科/专业筛选的一级分组。系统内置学院目录，当前包括基础物理与数学科学学院、物理与光电工程学院、化学与材料科学学院、生命与健康科学学院、药物科学与技术学院、环境学院、分子医学院和智能科学与技术学院。新增其他学院的培养方案时，只需在每个方案中填写所属学院名称；页面会自动生成对应分组，不需要修改筛选组件。旧版自定义方案没有该字段时，会安全归入“其他培养方案”或“其他学科/专业”。同一学院下的多个培养类型和培养阶段可以继续共享学院分组，但仍通过各自的 `id`、培养方向和要求独立计算。

`publicRequiredCredits`、`professionalNonDegreeCredits` 或 `innovationCredits` 未在材料中明确时可填 `null`，网页会显示“材料未明确”或“不限”。当前内置的人工智能、材料工程培养方向按与光电信息工程相同的公共必修要求计为 8 学分。导入后网页会显示方案来源和更新时间，并按课程名称统计本学期课表中的可匹配课程。

## 导入 WakeUp 课程表

1. 先在课程列表中确认已选课程、班次、上课地点、星期、节次和周数均符合学校最终安排。
2. 点击右上角“导出 CSV”，保存生成的 CSV 文件。
3. 打开 WakeUp 课程表的导入功能，选择该 CSV 文件并检查导入预览。
4. 如学校课表或班次有调整，请重新核对后再导入；本工具不会替代学校正式选课系统。
